# 默认单页内容模板

文件：[default-template.pptx](../assets/default-template.pptx)，预览：[default-template.png](../assets/default-template.png)。模板只有一页内容页，无封面。按请求复制到所需页数，更新页码；用户明确提供其他模板时以其他模板为准。

## 固定视觉参数

| 项目 | 参数 |
| --- | --- |
| 画幅 | 16:9；12192000 × 6858000 EMU，即 1280 × 720 CSS px |
| 字体 | 微软雅黑 |
| 标题 | 32 pt，粗体，黑色 |
| 上方说明 | 20 pt，粗体，黑色 |
| 下方结论 | 18 pt，粗体，黑色 |
| 页码 | 13.35 pt，常规，灰色 `#808080` |
| 主色 | 深蓝 `#003399`；白底 |

标题、说明和结论的字号分别匹配参考稿对应角色；结论为 18 pt，不随说明改成 20 pt。

## 新页眉与内容区域

页眉采用左对齐黑色标题，标题下方以纯深蓝细横线分隔正文。横线与正文区域等宽，两端保留页面留白；各主区域左侧对齐在 x=42 px。

| 对象名 | x / y / 宽 / 高（CSS px） | 用途 |
| --- | --- | --- |
| Header accent | 42 / 92 / 1196 / 3 | 标题下方可编辑蓝色分隔线 |
| Title | 42 / 28 / 1196 / 54 | 本页标题 |
| Explanation | 42 / 108 / 1196 / 52 | 1–2 句上方说明 |
| Evidence placeholder frame | 42 / 178 / 1196 / 415 | 图证据区域的临时边界 |
| Conclusion | 42 / 620 / 1160 / 69 | 1–2 句有依据的结论 |
| Page number | 1226 / 679 / 30 / 26 | 页码 |

制作正式报告时，替换标题、说明和结论，移除 `Evidence placeholder frame`、`Evidence placeholder` 和 `Evidence guidance` 三个占位对象，在中部区域插入实际图、表或模型。占位边框不是必须保留的模板装饰。所有文本和线条均为原生可编辑对象。

## 内容组织建议

- 标题概括本页研究对象与分析内容，例如“多源激励下的能量流影响因素分析”；具体数值和结果写入下方结论。标题可用副标题细化范围，不限定破折号格式。
- 默认将原文图号、页码和文献信息写入各页备注，不在说明与结论之间预留固定“来源”行。展示面仍保留理解图表所需的名称、单位和图例；有明确页内引用要求时另作紧凑安排。
- 中部包含同一主题的多个零散对象时，可另建可编辑的内容分组框。建议白底、约 0.75–1 pt 的细边框，需标题栏时采用 `#003399` 矩形块与白色粗体字，字体沿用微软雅黑。标题栏应能概括组内全部内容，字号按同级标签协调，不增加新的固定字号角色。框用于建立内容归属，不能直接保留整块占位框来代替分组判断。
- 在 1280 × 720 画布下，可先以组内约 12–16 px 的内边距、独立内容块约 16–24 px 的间隔安排，再按实际文字高度与视觉密度调整；组间间距应明显大于同组元素间距。这些是排版起点，不是所有页面的硬性数值。保持中部内容与 y=620 px 起始的结论区之间清楚的留白，不让图注、参数说明或框线贴住结论。
- 移除来源行或增加分组框后，重新检查内容宽度、文本换行及内外间距，不以缩小模板文字解决拥挤。并排内容保持各自的视觉归属，避免为追求统一给所有图表再套一层框。
